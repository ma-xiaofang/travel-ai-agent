# 2026-07-15 工作日志

## Markdown 渲染方案最终定型 — 零依赖纯正则

### 问题背景
- `marked` npm 包在小程序中编译后依赖 `@swc/helpers` 的 `_.wrap_reg_exp`，运行时报 `module not defined`
- `@ant-design/x-markdown-mini` 的 `parse()` 在小程序运行时抛 `TypeError: Function.prototype.toString called on incompatible object`，导致 `renderMarkdown` 走 catch 分支返回原始 markdown（`**` 星号直接显示）
- mp-html 的 `tag-style` 属性必须用 `:tag-style="obj"` 绑定对象，不能用 `tag-style="{{...}}"` 字符串语法

### 最终方案
- 完全移除 `marked` 和 `@ant-design/x-markdown-mini` 依赖
- 在 `chat/index.vue` 中内置零依赖的 `renderMarkdown()` 函数，纯正则实现
- 支持：标题(h1-h4)、粗体(`**`)、斜体(`*`)、删除线(`~~`)、代码块(```)、行内代码(`)、列表(ul/ol)、引用(`>`)、表格(GFM)、链接、图片、分割线
- 行内格式用 `<b>`/`<i>`/`<del>` 标签（mp-html trustTags 包含这些）
- tag-style 中对应 `b`/`i`/`del` 设置样式
- 流式友好：未闭合的代码块也能正常渲染
- `var(--chat-font-size)` CSS 变量在 tag-style 中使用，通过页面 `:style` 绑定

### 文件变更
- `apps/miniprogram/src/pages/chat/index.vue` — 替换整个 markdown 渲染逻辑
- `apps/miniprogram/package.json` — 移除 marked、@ant-design/x-markdown-mini 依赖
