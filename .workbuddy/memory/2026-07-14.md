### AI 对话字号自适应
**文件**: `apps/miniprogram/src/pages/chat/index.vue`
- 目标：以 18px 物理字号为基准，在不同宽度设备上保持舒适阅读大小
- 实现：
  - 通过 `uni.getSystemInfoSync().windowWidth` 计算 CSS 变量 `--chat-font-size`
  - 公式：`Math.round(18 * 750 / windowWidth)` rpx
  - 例：iPhone 375 → 36rpx；iPhone 390 → 35rpx；iPad 768 → 18rpx（物理大小均约 18px）
- 应用范围：
  - `.ai-msg` 正文与 `.ai-content` 流式文本使用 `var(--chat-font-size)`
  - `mp-html` 的 `p/li/td/th/blockquote` 等使用 `var(--chat-font-size)`，标题使用 `em` 相对倍数（h1 1.5em, h2 1.3em 等）
  - 重新编译，产物已更新
